# Text-to-RIR Listening Test

A perceptual evaluation (MOS) web interface for assessing the quality of text-conditioned room impulse response generation.

## Overview

This site hosts a listening test to evaluate synthesized room impulse responses (RIRs) generated from text descriptions. Participants listen to audio samples convolved with generated RIRs and rate perceived acoustic quality.

## Usage

Open the site in a browser and follow the on-screen instructions. Headphones are strongly recommended.
